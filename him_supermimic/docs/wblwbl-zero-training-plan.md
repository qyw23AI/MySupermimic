# WBLWBL Dog V1 从零训练对照

## 1. 对照组和随机初始化

比较从随机初始化到稳定行走的总用时。使用同一台机器和 GPU、Isaac Lab PhysX、Stage 3 平地，4096 环境，种子 611–615 成对。每个种子只随机初始化一次 HIM Actor 和编码器，两组复制相同张量并核对哈希。各组需要的其他网络独立随机初始化，优化器为空。两组均不使用历史模型、策略、回放或教师。

| 组 | 训练方法 |
|---|---|
| A | 纯 HIM-PPO，保留原 PPO 探索及更新 |
| B | HIM + SuperMimic，用本次仿真回放训练世界模型，Actor 只用 BPTT 更新，全程无 PPO 更新和 PPO 热启动 |
| C（可选） | HIM-PPO + 受约束的 BPTT，从同一随机策略起跑，单独报告 |

B 可用本次真实转移执行原 HIM 的速度监督与对比学习。BPTT 时冻结模型和 HIM 编码器参数，保留对输入的梯度。C 不计入 A/B 主比较。

## 2. 两组环境与奖励完全一致

主实验用现有 A5 已验证对齐的 `core_reward_v1` 受控平地配置。A 与 B 从同一个构造函数读取环境配置，比较完整配置快照和哈希。锁定 MyHIMLoco 提交、URDF 和地面 USD、PhysX 与控制步长、关节顺序、PD 和动作限幅、观测噪声、出生状态、随机化、真实接触终止、超时、命令范围、重采样和课程开关。训练指令由相同的预生成种子流驱动，因策略不同触发的 reset 可以造成路径分叉。评估则使用按控制步索引的固定指令表和相同初始分布。

`core_reward_v1` 与原版完整奖励有范围差异，省略项由现有清单统一配置。两组真实环境的奖励项、权重、计算时点和 dt 完全相同；B 的可微奖励逐项与这份配置对齐。锚定损失仅作用于 B 的优化器，单独记录，不计入任务奖励或最终得分。若需要对原版全部奖励做提速声明，先为完整配置验证所有可微奖励项，再用同样的两组协议单独复验。

开跑前在随机策略与已出现接触终止的轨迹上检查奖励分项和总和、指令重采样、超时/终止，以及 reset 前观测。固定动作和指令时，两侧应复现相同真实轨迹；可微奖励重建最大绝对误差目标为 1e-5。地面 USD 在本地准备并记录哈希。

## 3. SuperMimic 参数与冷启动

沿用 A5 的 8 步想象、每周期 8 次模型更新、Actor 学习率 5e-6、动作约束 0.01、尾值 0。B 无需 PPO Critic 或预训练 Critic。模型训练从每批 256 个窗口起步，采样从每环境每周期 8 步起步，开发阶段确认覆盖率后锁定。

1. **冷启动采样。** 执行共享随机初始 Actor 的动作均值加零均值探索噪声，初始尺度参考 A 的探索配置。动作限幅、PD、环境和 reset 规则两组一致。记录跌倒、动作裁剪、有效窗口及转向覆盖。初始策略短回合导致 8 步窗口不足时，在开发阶段验证带掩码的短窗口或时间相关探索，锁定后再跑确认组。
2. **模型放行。** 从零拟合本次采样的 reset 前状态和执行动作，验证按回合分组，不跨 reset。分别检查独立回合上的多步预测、偏航动作响应、接触终止以及成对仿真中的候选更新收益。Actor 起点独立抽样，不要求未来继续存活 8 步。开发阶段锁定放行条件和冷启动预算。预算内未放行记为失败。
3. **在线循环。** 真实采样、模型拟合、BPTT 候选更新依次执行。想象使用共享奖励，并验证指令边界与真实终止对齐。动作约束的参考取当前周期 BPTT 前的策略快照。首步在快照处的锚定梯度为零，因此另用实际动作 RMS/P95 限制候选步，超限则缩小或回退 Actor 及优化器。记录提议、接受、拒绝与回滚次数，并按固定频率复查模型和真实闭环表现。

历史 A5 在会走策略上验证了这些参数的短期表现。冷启动探索和从零学习需要用本实验单独确认。B 预算内未学会走路时报告未达标。C 可用于判断加入 PPO 更新后能否弥补这个缺口。

## 4. 预先锁定行走门槛和测量时间

使用 P0 的统一 reset 前评估实现。先在独立开发种子运行纯 HIM-PPO 并验证下述门槛可达，再锁定指令文件、门槛和评估代码。建议采用以下绝对值，参考此前会走的初始策略在 P0 的 0.128 m/s、0.487 rad/s、0.0404 回报及零跌倒量级。这些是拟定工程门槛。

| 指标 | 稳定行走门槛 |
|---|---:|
| 平面线速度 RMSE | ≤ 0.14 m/s |
| 偏航角速度 RMSE | ≤ 0.50 rad/s |
| 每步任务回报 | ≥ 0.039 |
| 跌倒频率 | ≤ 0.02 次／机器人分钟 |

指令覆盖静止、前进、后退、左右横移、原地转向、弧线和阶跃，逐类输出指标，共享预生成指令文件。若任务合法指令范围不含某类，开发阶段移除该类并锁定。每个评估种子 1024 环境，至少 1500 控制步并覆盖一个完整回合时限，使用确定性动作。统计终止前转移、跌倒和超时；保留速度及奖励分项。确认组固定两个指令集，开发检查 801/802/803，最终留出 901/902/903。每累计约 200 万训练转移，在最近一次完整更新后使用同一评估，连续两次过线才记达标，首次达标时间记为第二次评估结束。对该点做留出复核。留出不过则标为达标未确认，并公布结果。记录评估实际发生的控制转移数，反映两组各自更新周期的取整差异。

主效率指标是同种子的 PPO 达标墙钟秒数除以 B 达标墙钟秒数。另报告训练控制转移之比，区分物理采样、优化、模型门控、评估、诊断和冷启动耗时。统一从进程启动计时，冷启动采样、模型拟合和放行检查全部计入。配对发布每个种子的速度比及中位数，超预算未达标按未达标报告。建议工程目标为 5 对种子均达到门槛，且墙钟速度比中位数至少 2。固定预算内还比较 A、B 的最终指标，建议 B 相对 A 的两项跟踪误差不高于 105%、回报不低于 98%、跌倒率最多增加 0.02 次／机器人分钟。不能用中途最佳检查点代替预算结束的成绩。

## 5. 实现和执行顺序

1. 抽出共享随机初始化、任务构造和评估。A 复用纯 HIM-PPO 入口。B 新建纯 BPTT 冷启动入口，复用现有模型拟合和 BPTT 组件。现有在线入口强制加载策略、世界模型、Critic 与回放，需要解除这些依赖。
2. 用 64 个环境验证初始权重与环境配置一致、固定动作回放一致、B 的模型从本组仿真数据学习，以及 BPTT 关闭时 Actor 权重保持原样。检查候选回退是否恢复优化器。
3. 用独立开发种子校准探索、冷启动和模型放行。以约 9830 万训练控制转移为共同预算参考，另锁同一墙钟上限。确认实验前固定协议。
4. 运行 5 对 A/B，按种子交换运行顺序，保存检查点、评估明细与时间分解至 him_supermimic/outputs/zero-start。可选 C 单独记录。中断后仅恢复本次运行产生的状态，延续累计计时。
5. 报告每组达标数、失败阶段和固定预算终点成绩，成对达标时再计算速度比。物理步数降低但墙钟持平时记录为采样效率改善。
