# AMP 动作数据使用说明

本文件定义 `amp_supermimic/data` 后续数据检索、重定向和训练的数据范围。操作前先读本文件，再按下方规则构建文件清单。

## 永久排除的 WBLWBL 动作

`wblwbl/rubbish/` 及其全部子目录是用户筛出的低质量动作归档。当前包含一般淘汰动作、`waitingFor/` 中等待复核的动作，以及 `waitingFor/supplemental_a1/` 中的 A1 补充转向。

后续工作必须将 `wblwbl/rubbish/**` 视为排除范围：

- 检索新专家动作时，不从该目录读取、筛选、抽取或重用动作数据，也不把里面的动作名称当作待补充目标。
- 重定向和训练输入清单不得包含该目录下的 CSV、NPZ、JSON、MP4 或其他文件。
- 递归扫描 `data/` 时，在遍历入口排除整个 `wblwbl/rubbish/` 子树。不得通过复制、改名或生成新索引把这些动作重新带回候选集。
- 此目录只保留作排除标记。其文件、报告和预览视频不构成通过审核的正面样例。

任何历史目录或脚本生成的清单都不能覆盖这条排除规则。特别是旧的 `action_index.json` 可能仍引用后来移入 `rubbish/` 的路径，使用前必须先核对路径并过滤排除目录。

## 候选数据准入

只从非排除目录中的原始来源或用户明确保留的候选生成新训练清单。确认来源、数据布局、关节顺序、四元数顺序和许可信息后再做重定向。重定向结果先做运动学拟合、关节限位和速度检查，再独立做目标机器人动力学回放。报告中的 `motion_usable_for_amp` 只表示运动学筛选通过，不能单独证明机器人能跟踪；最终训练白名单应按完整回放结果和用户筛选维护。

原始来源位于 `raw/`，Go2 表示位于 `go2/`，WBLWBL 的整理轨迹位于 `wblwbl/`。原始来源、转换轨迹、派生片段、回放状态文件和 MP4 预览属于不同数据用途，不能因文件存在或有 `train.json` 就自动加入训练。

## 数据目录索引

- `raw/`：原始下载、来源信息和许可文件。
- `go2/`：Go2 参考轨迹及其目录清单。
- `wblwbl/`：WBLWBL 目标机器人上的候选轨迹。每次使用时排除 `rubbish/`，并逐条复核质量报告。
- `configs/`：数据集文件列表配置。
- [MOTION_INVENTORY.md](MOTION_INVENTORY.md)：来源种类、重复关系与历史数据盘点。该盘点是描述材料，不生成训练白名单。
